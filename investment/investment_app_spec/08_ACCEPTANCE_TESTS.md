# Acceptance & Quality Tests v1.2 — 最終設計

更新：2026-09-10。具体的な入力・期待結果・検証方法は[12_PHASE_ACCEPTANCE_PLAN.md](12_PHASE_ACCEPTANCE_PLAN.md)に定義。本文は必須品質要件。

# A. 要件整合テスト
1. スイングで週足が日足より大局判断に使われる。
2. 投資妙味とEntry品質が分離される。
3. 好業績だけで高評価にならず、上方修正余地/期待差を評価する。
4. PER単独で売買判断しない。
5. マクロはセクター/企業感応度を介して評価する。
6. RR不足で自動見送りせず条件付き表示できる。
7. 現値から上値7%未満なら「良い銘柄だが押し目待ち」を表現できる。
8. 決算1か月以内（Swing）を必ず表示する。
9. 通常損切と撤退条件が分かれる。
10. ユーザー提供の最新スクショが古い外部データより優先される。

# B. シナリオテスト
## 1. 良企業・高値圏
Critical／Severe・例外材料がない通常ケースで、投資妙味>=7、Entry<5、判定=押し目待ちになること。

## 2. 回復株
現在業績は弱いが受注/利益率/上方修正期待が強い場合、機械的に低評価にならないこと。

## 3. セクター逆風＋巨額受注
支配的個別材料として定性オーバーライド候補になること。

## 4. 好決算織り込み済み
業績高評価でも期待差が低く、投資妙味が過大評価されないこと。

## 5. RR悪化
投資妙味を維持しつつEntry品質が低下すること。

## 6. データ不足デイトレ
前日データしかなければ精密点数を出さないこと。

# C. 算術・再現性
- 同一入力・同一Evidence・同一の採用済み採点基準選択・同一規則版で、構造化評価の集計値と価格計算が一致する。
- AIは構造化評価・定性コンテキスト評価ともに採点基準とEvidenceを必須とし、自由な点数を返さない。
- 低ランダム性だけでAI判断の同一性を保証せず、実出力を保存して再現する。
- 価格計算はプログラムで実施。

# D. バックテスト/フォワード検証
判定時点以降の1週/1か月/3か月について、
- 最大上昇率
- 最大下落率
- 第1/最終利確到達
- 第1/最終損切到達
- 到達日数
を保存する。

高スコア群が低スコア群より統計的に良好かを定期検証する。
単発結果で配点を変更しない。

# E. 品質ゲート
Codex実装は以下を満たすまでMVP完了としない。
- スコア計算単体テスト
- Entry/Exitロジック単体テスト
- 欠損データテスト
- 時刻/営業日テスト
- Evidence追跡テスト
- 代表10銘柄の手動レビュー：最終判断・銘柄順位・主要理由の整合を優先し、スコア差は補助として記録

# F. 今回確定した方針の必須テスト
- 全時間軸で構造化評価70%＋定性コンテキスト評価30%。Entry品質を混合しない。
- デイトレの投資妙味にRR・支持抵抗距離を二重計上しない。
- 欠損は暫定評価／評価不能で、0点・自動見送りではない。
- Criticalは対象評価が成立しない。Severeは警告付き条件判断とユーザー買い承認を必要とし、機械的見送りにはしない。Warningは条件へ反映。
- 上書きによってCriticalや他の未充足例外条件を無視しない。
- RRは（第1利確 − Entry）÷（Entry − 第1損切）。損切をRRから逆算して変更しない。
- RRが悪い場合はEntry改善。利確・損切の根拠を固定した比較を行う。
- 上値7%未満は原則押し目待ち。支配的材料と合理的RRの両方がある例外のみ記録付きで許容。
- 決算跨ぎ未入力では複数シナリオ。予定日欠損は推測しない。
- 有料データ未契約でも無料＋手動入力経路が動く。
- 口座番号・残高等を外部AI・外部ログへ送信しない。
- 代表10銘柄について最終判断・順位・主要理由を比較できる。点差だけでは不合格にしない。重大不一致を放置してMVP完了にしない。

# G. 最終設計の追加検証
- 13の全69主カードとME-E下位基準にEvidence・理由・反証・欠損処理がある。
- 数値補間は許可項目のみ。AI自由採点なし。
- RR2.0/1.5の境界、1.5〜2.0条件付き、1.5未満の支配的材料による例外を検証。
- 支持抵抗configは版管理し、Swingの週足・主要高安・実測価格別出来高優先を維持。
- Severeのpending/approved/rejected/expired、対象ハッシュ、不正な承認流用、Criticalとの競合を検証。
- 人間比較では点数が違っても判断・順位・理由が一致すればそれを評価し、同点でも重大見落としがあれば不合格。
