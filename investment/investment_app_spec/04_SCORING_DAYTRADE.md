# Daytrade Scoring Specification v1.2

更新：2026-09-10。ユーザーからの配点確定の委任に基づき、以下の新配点を確定。採点カードは13。

デイトレは補助機能。情報不足時は無理に精密採点しない。

## 1. Preflightと評価状態
独立して重大悪材料、投資前提崩れ、流動性、データ充足を確認する。
Critical / Severe / Warningの意味と判断優先順位は07に従う。
以下の不足は暫定評価／評価不能として管理し、0点や自動見送りにはしない。
- 当日価格
- 当日出来高
- 当日高安
- 直近材料の確認

板・歩み値は補助情報。未取得を「板が良好」と扱わない。

## 2. 投資妙味／当日機会の責務
当日その銘柄へ注目する価値を、次の異なる評価目的で整理する。
- 当日材料のインパクト、未織り込み
- 当日の参加者・売買代金・継続的な需給
- 方向性・モメンタムの継続性
- セクターからドライバー、企業感応度、個別材料との比較を経た当日追い風
- 材料の持続性・当日中の発現可能性

上値抵抗までの距離、支持帯の近さ、RR、具体的Entry位置、瞬間的な約定条件はEntry品質だけで採点する。
旧版の投資妙味E「日足上の位置・上値余地」、F「支持・抵抗・RR」の配点表は廃止する。
新配点は次のとおり。既存の当日機会評価を維持し、Entry目的の項目を分離した。

| 投資妙味の構造化評価 | 配点 |
|---|---:|
| A 当日材料・未織り込み | 30 |
| B 参加者・継続需給 | 20 |
| C 方向・継続性 | 20 |
| D セクター・企業への伝播 | 15 |
| E 当日中の材料発現可能性 | 15 |
| 合計 | 100 |

| Entry品質 | 配点 |
|---|---:|
| A 上値余地・直近抵抗 | 20 |
| B 支持・無効化条件 | 20 |
| C RR | 20 |
| D Entryトリガー | 20 |
| E 執行時の確認 | 10 |
| F イベント時刻 | 10 |
| 合計 | 100 |

コンテキスト4テーマは各25%。各配点の下位カード、観測区間、Evidenceは13・14で定義する。

## 3. 定性コンテキスト評価
投資妙味 = 構造化評価×0.70 + 定性コンテキスト評価×0.30。
構造化評価は数値計算と、採点基準・Evidenceに基づく評価を含む。
定性コンテキスト評価は、当日材料の持続、参加者交代、個別／セクター支配力、失速・反証リスクを整理する。
AIは定義済み基準の選択とEvidence提示を行い、自由に数値を付けない。
採点基準と項目重みは13および11のP01・P03。

## 4. Entry品質
プログラム生成のEntryPlanを参照し、投資妙味とは独立して0〜10点に集計する。
- 直近抵抗までの上値余地
- 支持・シナリオ無効化水準
- 第1利確と第1損切によるRR
- 反転／ブレイク等の具体的なEntryトリガー
- Entry時の出来高確認・スプレッド等の執行条件
- 直近イベントとEntry時刻の関係

同一分析時点で算定できるが、得点内訳と評価目的は別に保存する。
投資妙味の継続需給とEntry時の約定条件は別の特徴量・観測区間を使う。同じ特徴量を同じ目的で二重加点しない。

## 5. 決算・時間軸
1週間以内のみ決算の重要度を高める。発表当日／翌日は「決算イベント」局面として評価。
スイング専用の7%未満ルールは適用しない。
当日中のExit・価格戦略は11のP08・14。

## 6. データ鮮度
- 当日価格／出来高：5分以内を推奨
- 15分超：信頼度低下、暫定扱いの規則は11のP02
- 前日値しかない：デイトレ点数を出さず評価不能
