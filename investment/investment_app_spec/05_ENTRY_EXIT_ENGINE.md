# Entry / Exit Engine Specification v1.3

更新：2026-09-10。RR式、損切先行、7%未満の例外を確定方針に合わせて改訂。

## 1. 基本思想
価格目標をAIが自由生成しない。プログラムが実データから候補価格帯を生成し、AIは文脈と根拠を評価する。
第1損切＝通常損切。最終損切および価格に依存しない撤退条件とは分ける。
RR =（第1利確 − Entry）÷（Entry − 第1損切）。

## 2. 支持・抵抗候補
- 直近／過去高値・安値
- 13/25/50/75日線、13/26/52週線
- Bollinger Bands
- Fibonacci 23.6/38.2/50/61.8/78.6
- 価格別出来高、窓、心理的節目

欠損した指標をAIで補わない。日足OHLCと総出来高から作る近似分布を実測の価格別出来高と呼ばない。
Fibの起点と高安の確定条件には分析時点以降の情報を使わない。

## 3. Confluence（近接する支持・抵抗の重複帯）
価格差とATR等に応じて近接価格帯をまとめる。強度評価：
- 独立した根拠の種類（同系列指標の過大な二重計上を避ける）
- 週足根拠を日足より重視
- 過去反応回数、出来高量、直近性

許容幅・強度係数の初期値は14。将来の実績検証で校正可能なconfigとして版管理する設計とし、今回はconfigファイルを作成しない。
スイングでは週足、主要高安、実測価格別出来高を優先し、同系列の派生指標の本数で強度を水増ししない。

## 4. 算出順序
1. 分析時点、時間軸、現値／指定Entry、局面を固定。
2. 実支持帯とシナリオ無効化条件を特定し、第1損切・最終損切を先に定める。
3. 抵抗帯等から第1利確・最終利確を算出。
4. Entry候補を定め、上記の固定された根拠付き水準でRRを算出。
5. RRが悪い場合はEntry価格改善を検討し、押し目・反転・ブレイク待ちのプランを生成。
6. 根拠のない改善価格、ゼロ以下の損切距離、利確がEntry以下の場合は有効プランにしない。

RR>=2.0は良好、1.5<=RR<2.0は条件付き、RR<1.5は原則Entry改善・押し目待ち。
1.5未満は買いを支持する支配的材料がある場合のみ例外を検討できる。RR単独で見送りへ足切りしない。
損切価格をRRから逆算して移動しない。
同じシナリオのEntry比較では利確と損切を固定する。
新しい支持帯等でシナリオが本当に変わる場合は、新しいプランと根拠・変更理由を保存する。

## 5. 利確と7%未満ルール（スイング）
1. 現値+7〜20%を基本探索範囲としつつ、7%未満の手前抵抗も必ず検出する。
2. 最初の有力抵抗帯を第1利確、次の有力帯／強気シナリオを最終利確候補とする。
3. 強烈な業績・材料変化時は20%上限を外せるが、目標の根拠は必須。
4. 現値から第1利確まで7%未満は原則押し目待ち。投資妙味は原則下げずEntry品質へ反映。
5. 現実的な利確水準を維持し、現値の約10%下を探索起点として実支持帯へ補正する。
6. 押し目Entry候補の約5%下は次の支持帯探索の目安。実支持帯・無効化条件から損切を定める。
7. 支配的材料と合理的RRの両方が成立する場合のみ例外を許容し、理由・Evidence・基準価格・プランを記録。

10%/5%は固定注文価格ではない。ATR・週足構造・銘柄の変動性で補正する。
「約5%下」の基準を押し目候補とするのは設計上の明確化。RR区分と例外審査は11のP04。2.0未満でも条件や支配的材料を評価し、機械的な足切りにしない。
指定Entryについても別シナリオの上値余地とRRを計算し、現値判断を上書きしない。
中長期・デイトレに7%条件を流用しない。

## 6. Alert
第1損切に達する前の再評価開始価格。Alertは自動売却ではない。
買い方向プランでは第1損切 < Alert < Entryを検証。根拠がなければ未算出。
価格の監視・通知の自動実行はMVPの確定要件ではない。

## 7. 損切と撤退
第1損切：テクニカル・需給上のシナリオが弱まる価格。
最終損切：価格構造上のシナリオ完全否定水準。
撤退：価格とは別に投資前提が崩れた条件。
- 下方修正、受注急減、重要案件失注、希薄化、不正
- テーマ実需消失、競争優位崩壊、想定カタリスト消失

撤退条件はイベント名だけでなく当初の前提と、何が崩れたら撤退するかを保存する。
根拠のない第2の価格水準を必須表示のために捏造しない。

## 8. 今買う vs 待つ
Entry/Exit Engineは価格プランを生成し、最終売買判断はDecision Engineが行う。
- 今買う：上値余地、損切距離、RR、近いカタリスト、取り逃しリスク
- 待つ：押し目候補と根拠、反転確認価値、押し目なく上昇する機会損失

各プランに成立条件・失効条件を持たせ、決算跨ぎ未入力時は複数シナリオを比較する。
分割は実行方針として最終判断と別管理する設計（11のP07）。株数・金額・注文は扱わない。
