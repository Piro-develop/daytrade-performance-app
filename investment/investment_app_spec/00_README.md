# 日本株 投資判定アプリ — Codex設計投入パッケージ

## 目的
銘柄名/コードを入力すると、日本株について「デイトレ・スイング・中長期」の投資妙味を評価し、特にスイング/中長期を高品質に判定する。

本アプリの中心は点数ではなく、次の意思決定である。

1. この銘柄をこの時間軸で持つ価値があるか（投資妙味）
2. 今この価格で入る価値があるか（エントリー品質）
3. 今買うのか、押し目・反転・ブレイクを待つのか
4. どこで利確・損切するか
5. 何が起きたら投資前提を撤回するか

## 設計原則
- 企業評価と売買判断を分離する。
- 週足＝大局、日足＝タイミング。スイングは週足を優先する。
- 現在の好業績より、将来の上方修正・利益成長余地、市場期待との差を重視する。
- マクロは直接加減点せず、セクター→主要ドライバー→企業感応度→個別材料との強弱比較で評価する。
- スコアは比較・抜け漏れ防止のために使い、最終判断を機械化しない。
- 構造化評価70%＋定性コンテキスト評価30%を基本とし、支配的材料がある場合は最終判断を定性でオーバーライド可能とする。
- 投資妙味とEntry品質を別スコアで表示する。
- PreflightはCritical（評価不成立）/ Severe（警告付き条件判断、最終的な買いはユーザー承認必須）/ Warning（条件へ反映）の3段階。警告と評価状態と得点を分離する。
- 各判断はデータ、取得日時、根拠を追跡可能にする。
- 将来的に実績でスコアを校正する。

## 確定した共通規則
- 構造化評価は数値計算と、定められた採点基準・Evidenceに基づく評価を含む。AIの自由採点は禁止。
- 投資妙味 = 構造化評価×0.70 + 定性コンテキスト評価×0.30。Entry品質は独立評価。
- 無料データ＋CSV／スクリーンショットによる手動補完を許容。有料データは必須にしない。
- 必須データ不足は「暫定評価／評価不能」で管理し、0点や自動見送りへ変換しない。
- RR =（第1利確 − Entry）÷（Entry − 第1損切）。支持帯・シナリオ無効化条件から損切を先に定める。
- RRを良く見せるために損切を動かさない。RRが悪い場合はEntry価格の改善を検討する。
- スイングの上値7%未満は原則押し目待ち。支配的材料と合理的RRがある場合のみ例外を許容し、理由を保存。
- 決算跨ぎ方針は任意入力。未入力なら複数シナリオ表示。
- AI評価はEvidence必須。代表銘柄で人間評価との比較検証を可能にする。
- 外部AI等への送信対象は公開情報・分析用情報を中心とし、口座番号・残高等は対象外。
- 自動売買、株数・投資金額の算定は対象外。

## 実装開始前 最終設計版
- [13_SCORING_CARDS.md](13_SCORING_CARDS.md)：全時間軸の採点カード、5段階アンカー、Evidence要件
- [14_INITIAL_CONFIG.md](14_INITIAL_CONFIG.md)：支持抵抗の初期係数、計算・観測条件、将来校正の契約
- [15_FINAL_DESIGN.md](15_FINAL_DESIGN.md)：最終設計の入口、確定／初期値／実装時検証の区別

RR区分は2.0以上＝良好、1.5以上2.0未満＝条件付き、1.5未満＝原則Entry改善・押し目待ち。
1.5未満の例外には買いを支持する支配的材料が必要。RRのみのハードな足切りはしない。
Severeは機械的見送りにせず警告付き条件判断を表示し、AI単独で通常の買いへ確定しない。
人間比較は最終判断・銘柄順位・主要理由を優先し、スコア差は補助指標とする。
