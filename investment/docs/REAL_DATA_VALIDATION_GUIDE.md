# 実銘柄検証：準備するデータと操作手順
目的は「実際の判断として妥当か」を確認することです。アプリが起動することとは別に検証します。
現在は準備段階です。実銘柄の検証成績や有効性を確認済みとはしていません。

## 1. 最初に用意するもの
まず5銘柄を同じ分析時点で揃えてください。最大10銘柄まで同じグループに登録できます。
銘柄選定は利用者の候補・保有検討リストから行います。ここでは銘柄名や実数値を作っていません。

|必要物|具体的な内容|不足した場合|
|---|---|---|
|対象一覧|銘柄コード・会社名・比較する5〜10銘柄|分析対象を確定できない|
|共通の分析時点|例の形式 YYYY-MM-DDT16:00:00+09:00。全銘柄を同じ時点に固定|異時点の順位比較をしない|
|確定日足CSV|始値・高値・安値・終値・出来高・調整基準・日時。最低58確定週足を生成できる期間、目安300営業日以上。可能なら約3年|不足指標・カードは未評価|
|価格の出所|取得元、取得日、価格調整方法。分割前後の基準を統一|矛盾はCritical、値を推測しない|
|会社公式資料|最新決算短信・説明資料・会社計画・直近適時開示。原文URL／PDFと該当ページ|財務・材料カードを未評価|
|需給と比較資料|信用残・空売り等、同業比較、ベンチマークの同期間データ・比較目的|不足するカードは未評価|
|マクロ・個別材料|セクター、主要ドライバー、会社の感応度、個別との強弱比較の根拠|マクロ／関連コンテキスト未評価|
|呼値|対象価格帯で確認した有効な刻みと、公式表・確認した出所|正確な価格プランは未成立|
|取引カレンダー|価格履歴と分析日・次回決算までの実取引日と出所・版|営業日数未算出、確定週に制約|
|次回決算予定|発表日時と確認元。未公表・時刻不明はそのまま伝える|推測で時刻を埋めず該当評価は未確定|
|独立した人間評価|結果を見る前の最終判断・主要理由1〜3点・反証・根拠。順位・価格・補助スコアは任意|比較評価を開始しない|

口座番号・残高・保有金額・ログイン情報・APIキーは不要です。提供資料には含めないでください。
スクリーンショットは銘柄・日時・目盛り・出所が読めるもの。現版に画像自動読取はなく、確認した内容をEvidenceへ入力します。
日足CSVと公式資料があれば、まず不足の整理から始められます。全24手動カードを無理に埋める必要はありません。

## 2. 比較群の考え方
最初の5銘柄は通常押し目、良い企業だが高値、好決算織込済み、セクター逆風＋個別好材料、回復途上など、
異なる局面を含むようにします。10銘柄に広げる場合は低流動性・重大悪材料・決算接近・データ不足・ブレイク等を加えます。
これは観察する局面の例であり、特定銘柄の推奨ではありません。
同じ銘柄の別シナリオや訂正版を「別の1銘柄」として数えません。
Entry候補順位は、現在の条件が成立する比較可能な5銘柄が別途必要になることがあります。

## 3. 空テンプレート
`data/validation_templates.zip` を画面からダウンロードできます。
展開済みフォルダは `data/validation_templates/` です。

- prices.csv：銘柄ごとに日足を入力。
- evidence.csv：出所、観測・公表・取得日時、抜粋、資料位置、鮮度確認。
- scoring_cards.csv：24手動カード。全て「未評価」から開始。規定外の小数は受け付けない。
- cohort_plan.csv：対象一覧と局面を整理する控え。現版では1銘柄ずつ画面登録。
- human_review_notes.csv：独立評価の作業用控え。現版では画面から保存する。
- README.txt：用途の説明。

テンプレートに実在企業の数値・得点は入れていません。未知の値を0や中立6で埋めないでください。

## 4. 日足CSV
共通列：
`symbol_code,timestamp,open,high,low,close,volume,adjustment_basis`

日本語の対応列：
銘柄コード、日時、始値、高値、安値、終値、出来高、価格調整基準。
UTF-8とCP932（Windowsの日本語CSV）に対応します。
銘柄列・調整基準列がない場合は、画面で明示入力し確認チェックを付けて補えます。
異なる銘柄が混在するCSVは受け付けません。1銘柄ずつ分けてください。
通貨はJPY、日足のみ。株式分割調整や出来高単位は出所で確認します。

日付列しかない場合、`date` または `日付` を認識します。
全入力期間について原資料で確定時刻を確認したうえで、画面のHH:MM欄に明示した場合だけJSTの日時へ変換します。
期間途中で終了時刻が違う場合は、元CSVに各日正しいtimestampを用意してください。
未指定の時刻や未完成足を自動で補いません。元CSVハッシュ・文字コード・変換内容も保存します。

## 5. 根拠・カードの入力
検証画面の表へ直接入力するか、evidence.csvとscoring_cards.csvを読み込めます。
既存の補足JSONを読み込んで開始することもできます。

EvidenceにはID、資料名、URL／資料の保存先、3種類の日時、summaryを入れます。
summaryには事実・解釈の区別と該当ページ／表を記載します。ハッシュは入力抜粋からアプリが計算します。
原資料全体を取得して検証した証明ではありません。原PDFや元CSVも保管してください。
valid_untilはその資料の鮮度を再確認すべき期限です。source_qualityは原資料確認済み／二次出所等を選びます。

採点カードは根拠ID、アンカー1/4/6/8/10、カード固有の理由、主要反証を入力します。
画面でカードごとの5段階基準を確認できます。資料が不足するカードは「未評価」のまま残します。
SW-D1/D2、SE-A〜Fはプログラム計算で、手動点数では上書きしません。
現段階は人間の基準選択＋プログラム計算です。「AIと人間の比較を実施した」とは扱いません。

Preflightは重大悪材料・投資前提・流動性を別々に根拠付きで確認します。
警告はCritical/Severe/Warning、理由・対象・Evidence・解消条件を入力します。
見つからないことと未調査を混同しないでください。
支配的材料、Severeの例外理由、実測出来高分布は既存補足JSONの項目を保持できます。

## 6. 操作の順序
1. [実銘柄検証画面](http://127.0.0.1:8501/?workspace=validation) を開く。
2. グループ名と共通分析時点を登録。規則版も固定される。
3. 「1. 銘柄入力」でCSV・Evidence・カード・補足を入力し、不足確認後に凍結保存。
4. 「2. 人間評価」で、アプリ結果を見る前の判断・理由・反証・Evidenceを保存。
5. 跨ぐ／跨がないを両方比較する場合は、両方の人間評価を分析前に保存。
6. 「3. 分析」で人間評価保存済みの銘柄を分析。まず1銘柄で確認し、その後5〜10銘柄へ。
7. 「4. 差分確認」で結論・価格・点差を確認。リンク先で全Evidence・採点内訳も表示。
8. 主要理由の意味・主要反証を人間が照合し、6分類の差分と修正案を追記。
9. 比較CSVと、入力参照・根拠・人間評価・差分を含むJSONを保存。

人間評価は保存後に上書きしません。分析後の独立評価追加は拒否します。
訂正する場合は理由付きで入力の新版を作り、新しい人間評価と分析を残します。
一度アプリ結果を見た人の再評価は完全な盲検とは限りません。独立性は本人の申告と手順で確認します。
同じ人が手動採点と比較評価を行うと判断が似る可能性があるため、可能なら別の人が比較します。

## 7. 差分の6分類
|分類|確認する具体例|
|---|---|
|データ不足|必要資料なし、日時違い、古い値、会社計画と市場予想の取り違え|
|採点基準|アンカー条件・評価目的・同一事実の重複|
|支持抵抗判定|週足・主要高安・価格帯の採用、手前抵抗、独立根拠|
|RR|第1水準、呼値、損切固定、Entry改善の比較|
|定性評価|作用時期、見落とし、反証、マクロと個別の支配関係|
|Decision Engine|警告・トリガー・7%／RR例外・Severe承認の適用|

差分は複数分類を選べます。重大不一致は別フラグで残し、平均一致率で相殺しません。
解消済みとする場合は確認根拠が必要です。元の分析・価格・スコアは変更しません。
記録された未解消差分から確認・修正候補を表示しますが、規則や正本の自動書換えは行いません。

## 8. 成績の読み方
判断一致、Investment順位、現在のEntry候補順位、主要理由の一致を優先。
点数差は参考で、差が大きいことだけを不合格にしません。
順位は同時点で評価可能な5銘柄以上。人間の同順位ペアは除外、全同順位なら追加標本が必要です。
上位3の境界同順位は集合として表示します。Entry候補は現在の条件成立を先に確認し、その後Investment・Entry・根拠品質の順に比較します。
暫定・評価不能・Severe条件判断を通常の買い候補と一緒に順位づけしません。
確認未完了や実銘柄未入力の場合は、その状態を明示します。成績表示だけで自動合格にはしません。
初期目安は正本14（判断80%、順位80%、上位3重複2以上、主要理由80%、未解消重大不一致0）。
実AIは未接続です。今回の検証は人間が入力した採点・データに対するアプリ判断の妥当性を調べるものです。

## 9. ここで利用者に準備をお願いする内容
最初の提出は「5銘柄のコード・会社名」「共通分析時点」「各銘柄の日足CSV」「最新決算・主要材料の資料」で構いません。
加えて、取得できる呼値・取引カレンダー・需給・比較資料を添えてください。ないものは不足として列挙してください。
スコアやRRを手計算する必要はありません。独立した人間判断と主要理由はアプリ結果を見る前に記録してください。
この準備が揃うまでは、実銘柄の判定値・一致率・修正要否を作らず停止します。
