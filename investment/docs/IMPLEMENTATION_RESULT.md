StreamlitのAppTestで実際に「分析する」を押し、結果・必須表示・入力変更・履歴を確認しています。
別途、実プロセスのHTTPを確認しました。スクリーンショットによる見た目の比較は実施していません。

ユーザー指定の最低8条件：
- 二重スコアの分離：Entry変更で投資妙味不変。
- 高投資妙味・低Entry品質：押し目待ち。
- RR不足：損切を近づけず、同じ価格構造でEntry改善。
- 重大警告：高得点でCriticalやSevereを消さない。
- 欠損：nullのまま、0点や欠損だけの見送りにしない。
- 週足：週線と確定高安を計算し、日足の反転で週足方向を書き換えない。
- 再現：同一入力・規則で指標・価格プラン・集計結果一致。履歴IDは実行ごとに新規。
- 追跡：根拠ID→計算／元データ、規則ハッシュ、判断理由をSQLiteから再表示。
