# UAT開始版 実装セルフレビュー
2026-09-10。正本17文書は変更せず、15_FINAL_DESIGNを入口として実装を拡張。
最新ユーザー指示に従い、実銘柄検証・有用性評価はUATへ移し、機能接続と主要制御に検証を限定。

## 実装
- 従来スイング分析・実銘柄検証は維持。
- 13の69主カード＋ME-Eストレス下位基準を別catalogに追加。従来32カードのファイルは維持。
- 中長期は03の独立配点。週・月足の価格構造、ME-EはRRとストレス等重み。公式財務欠損はCritical。
- デイトレは04の独立配点。当日確定5分足と当日材料を使用。同時刻累積出来高・約定環境根拠を独立要求。
- 7%ルールをスイングに限定。全時間軸でRRは第1水準、損切は支持構造から先に決める。
- 価格構造不足なら未算出。中長期のみ、根拠付きEPS・倍率レンジを代替利確候補として使用可能。
- Critical/Severe/Warningと支配的材料上書きは既存Decision Engineへ接続。Severe承認は別履歴。
- 全時間軸を同一SQLiteトランザクションで保存。途中失敗では一部だけ保存しない。
- 入力・根拠・設定・規則版・判断理由の追跡を継続。画像はローカルへ保存。
- 無料日足Provider、ECB為替、Fedニュース、手動/CSV/画像、定性AI依頼・応答交換を追加。
- 上段に時間軸別要約、下段に詳細。期限切れ結果を現在のEntry推奨にしない。

## 検証
- 主要計算・警告・承認と新中核処理の計24ケースが成功。
- 評価レンジ・分足欠損の2ケース追加後、新中核7ケースが成功。
- 起動→架空1銘柄→3時間軸分析→保存、および中長期・デイトレ詳細の接続確認で例外なし。
- ECBの公開為替取得成功。Fedはこの環境で接続失敗し、InputErrorで手動補完へ案内。
- Evidence再入力のハッシュ安定性とAI説明の未出典数値拒否を追加確認。
- HTTPヘルスチェック200。追加インストール不要（requests/Pillowは既存環境にあり）。
- Stooqの日足Providerは実装済みだが、この作業では実銘柄取得の成功確認を行っていない。
- 多数銘柄の内部UAT、UIの文言網羅検証、投資有用性の判定は行わない。

## 未接続・制約
- 外部AI自動実行は未接続。接続先・キー・予算は将来のユーザー設定。定性応答の手動取込でUAT可能。
- 無料データだけで全財務・需給・イベント・リアルタイム情報が揃うとは扱わない。
- 日中分析は確定5分足CSVを使用。当日高安だけからの代替プラン・リアルタイム板・監視は未実装。
- 財務数値の取得・正規化の全面自動化は未実装。構造化の判断カードはユーザーが根拠に従い選択。
- AI説明の数値検査は根拠内の数値との文字照合。意味・単位・解釈の正しさはユーザーUATで確認する。
- 中長期の代替評価式は正のEPS×適合PERに限定。他業種固有式は未実装。
- 原資料の真偽・十分性は人間の確認が必要。Evidence IDがあることだけで投資判断の精度を保証しない。

## 過剰設計・技術的負債
- 常時監視、注文、課金、自動スクレイピング基盤は追加しない。
- 既存の検証画面と従来画面を残すため、入力UIに一部重複がある。UAT後に整理候補。
- 公開データの実環境可用性、取引所カレンダー、呼値の自動提供は今後の接続課題。
- 配点は正本どおり。調整対象の期間・閾値はconfig/horizons.json、既存technical係数はconfig/default.json。
- マクロの生データを直接得点に変換せず、伝播経路のEvidenceと理由を要求。

結論：手動補完を含むUAT開始が可能。全自動分析版や投資精度検証済み版の完成とは区別する。
