# 実装の初期値・制限
正本17文書は変更していません。2026-09-10時点のスイングVertical Sliceです。

|項目|設定・解釈|場所|
|---|---|---|
|RSI|14本の単純平均方式。方式を明示し、別方式への無言切替はしない|config/default.json|
|RSI過熱の目安|75以上では日足セットアップのプラス評価を制限|同上|
|支持への距離|損切距離/ATRの2・4・6を近接比較の目安|同上|

|取引カレンダー未設定|営業日数null、金曜15:30で週足確定、計画期限24時間の暫定値|Preflight/EntryExit|
|保存|LOCALAPPDATA内SQLite、schema_version=1、分析は追記|storage.py|
|ソースコード構成|1機能1Pythonモジュール。サービス分割・外向けAPIなし|src/investment_app|

基準は正本13のアンカーを優先します。数値が良くても10点の複数根拠等が揃わなければ、成立する下位アンカーを採用します。
強度係数等の校正には規則版の更新と過去データでの比較が必要です。旧履歴は変更しません。

## 今回の範囲で完成した経路
1銘柄の共通日足CSV・補足入力から、確定週足、価格帯、損切先行プラン、投資妙味、Entry品質、
警告、判断、決算シナリオ、Evidence、SQLite履歴、画面表示へ接続しています。
外部Provider契約とカード評価の接続口はありますが、ネットワーク取得・AI実推論・画像OCRは未接続です。

## 残る作業
- 実銘柄・実CSV・公式カレンダー・呼値表での入力検証。SBI独自形式アダプター。
- 財務・材料・市場予想・比較対象の数値正規化と自動指標計算。現状は根拠付き手動評価。
- 画像からの抽出、画像位置の対話入力。現状は確認した価格帯と出所を手動登録。
- 根拠の意味の確認と人間比較。合成データの成功は実投資精度の検証ではない。
- 取引データからの価格別出来高生成。現状は出所付きの実測分布を入力。
- 日付のみ・時刻未定の決算入力の専用画面。現状は不明を未評価として扱う。
- 多銘柄順位、中長期、デイトレ、事後実績の校正、人間比較レポート。
- 実AI接続時の公開情報限定の送信検査。現在は送信口自体がなく課金なし。
- 初心者向けに補足JSONを個別フォーム化する改善。現状は銘柄・価格・方針以外はJSON入力。
- DBの世代バックアップと保持期間。現段階で自動削除はしない。

## 自己レビュー上の注意
- 上値目安より手前の有力抵抗を優先し、都合のよい遠方の利確を選びません。
- 押し目候補は同じ構造の実支持価格です。10%下は探索目安であり、固定価格やRRのための損切を作りません。
- 将来の押し目で出来高が確認できたように扱わず、Entry品質は未算出のまま不足理由を示します。
- データ信頼度は採点カードの必須Evidenceを一組単位で数えます。組に含む全資料の確認責任は手動採点者にあります。
- JSONの型・ID・日時は検査できますが、文章の真実性や同じ理由の重複を機械だけで証明しません。
- スイング試用版が動くことと、正本12の全66受入ケース・人間比較が完了することを区別します。
