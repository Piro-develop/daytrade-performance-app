# トラッカー内の投資判定機能

起動入口は親フォルダの start-uat.ps1 です。このフォルダだけを別アプリとして配布しません。
正本は investment_app_spec/15_FINAL_DESIGN.md を入口とする17文書。
同梱の docs/IMPLEMENTATION_RESULT.md 等は参照元の過去の実装報告です。
統合後の起動・制約・確認結果は親フォルダの docs/INTEGRATED_UAT.md、
docs/INTEGRATION_RESULT.md を参照してください。

採点・Decision・Entry/Exit・保存処理と正本配点は元実装を維持しています。
統合差分は画面、保存先の初期値、内部リンク、共有銘柄マスタ参照とデータ接続の利用条件です。
