# 通常タブへの統合確認（2026-09-11）

- 既存のナビゲーションに［銘柄判断］を追加。iframeとゲストUAT入口を削除。

- 3時間軸の独立評価、10点満点の投資妙味とEntry品質、売買価格、RR、今買う／待つ、警告、撤退条件、信頼度を表示。
- 既存コードを使った無料マクロ資料取得、定性AIの手動JSON交換、Severe承認履歴を接続。
- Google IDトークンの検証、利用者別SQLite・画像保存、ログアウト時の入力・結果消去を追加。
- 分析IDと比較用JSONを維持。元の売買データ・Firestore設定・ルールは変更なし。
- 通常サーバーは app_server.py。StreamlitおよびUATゲートウェイを本番経路で起動しない。

## 保存データへの影響

既存売買データと旧UATの保存先は触れていない。
検証データは .runtime と pytest用フォルダだけに保存。
通常版はユーザーホーム/.trading-journal に新規の本人別保存領域を使う。
元判定プロジェクトのソース・正本・保存DBも変更していない。
