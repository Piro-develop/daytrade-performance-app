# 統合UAT版の実装結果

確認日：2026-09-11。外部公開前の個人用UAT版。

## 統合した内容

- 既存メニューに「新規銘柄判定」を追加。同じURL・トラッカー内の画面で利用。
- スイング／中長期／デイトレ、二重スコア、Entry・利確・Alert・損切・RR、
  Preflight、重大警告、Severe承認、Evidence、履歴、実銘柄比較を統合。
- スマホの結果を2列カード化。結論・推奨時間軸・価格・最大懸念を先に表示。
  詳細分析は展開式。上段と詳細のシナリオ選択を共通化。
- 銘柄辞書は既存stocks.jsonを共用。既存成績の100点評価と投資妙味の10点評価は別機能として維持。
- 無料Provider、CSV、画像目視確認を再利用。Windows専用の将来接続を区別。
- run_idをanalysis_idとして、将来の取引比較に使えるJSONを出力。
- UAT保存先を専用フォルダに分離し、再起動しても同じ保存先を利用する。
- アクセスコードの入口、HTTP／WebSocket／アップロードを同じURLで提供。
  配信ファイルを限定し、DB・ログ・ソース・非公開画像を配信しない。

## 既存機能・正本の維持

既存app.jsの変更は新しい画面見出し、判定表示時の買付ボタン制御、画面起動イベントのみ。
Firestore設定、認証設定、保存スキーマ、売買記録、既存損益・税額計算モジュールは変更なし。

正本17文書、採点config 5ファイル、中核Python 16ファイルは参照元とバイト単位で一致。
SHA-256一覧：INTEGRATION_SOURCE_HASHES.json。
参照元プロジェクトのソース・DB・環境は変更していない。

## このPCの実行環境

新規 .venv への依存パッケージ導入は完了したが、NumPy DLLがWindowsの
アプリケーション制御ポリシーで拒否された。Windowsの制限を変更せず、
動作確認済みの既存Pythonを .runtime/python-path.txt に設定した。
現在は009側の .venv のライブラリを使う。009側のアプリ・仕様・ソースは実行時に参照しない。
別PCでは同梱requirementsから独立した環境を作成できる。

起動方法とアクセスコードは [統合UATガイド](INTEGRATED_UAT.md)。
現在の実保存先・URL・PIDはGit対象外の .runtime/server.json に記録する。
実行環境と保存先のPC固有設定もGit対象外。
